# 💻 Source Code Architecture (`src/`)

يحتوي هذا المجلد على الكود البرمجي الكامل لمنظومة **VERA (Verified Evidence Retrieval Assistant)** مقسمة إلى طبقات معمارية واضحة ومستقلة وقابلة للاختبار.

---

## 🏛️ الهيكل المعماري البرمجي

```
src/
├── config.py                 # تحميل وإدارة إعدادات النظام
├── ingestion/                # الطبقة 1: استخراج وقراءة الـ PDFs والتقطيع الواعي بالأقسام
├── embeddings/               # توليد المتجهات وبناء الفهرس الشعاعي (ChromaDB)
├── retrieval/                # الطبقة 2: البحث الدلالي والهجين وتوسيع الاستعلامات
├── generation/               # الطبقة 3: التوليد المنضبط بالأدلة وصياغة الاقتباسات
├── safety/                   # الطبقة 4: بوابات الأمان، كشف الهلوسة، ومحرك الرفض
├── evaluation/               # أجنحة التقييم والقياسات المعيارية (Precision@K, Faithfulness)
└── utils/                    # دوال المساعدة، السجلات، وتنسيق المخرجات
```

---

## 🔗 الارتباط بأيام الهاكاثون (Day 1 - Day 5)

| اليوم | الوحدة المعمارية | الوظيفة |
| :--- | :--- | :--- |
| **Day 1** | `src/ingestion/` + `src/embeddings/` | قراءة ملفات الـ PDF، التقطيع الواعي، وتوليد الفهرس الشعاعي. |
| **Day 2** | `src/retrieval/` | تحسين الاسترجاع، Top-K، البحث الهجين، وتصفية الدرجات. |
| **Day 3** | `src/generation/` | التوليد المنضبط بالأدلة الصارمة وصياغة الاستشهادات بالصفحات. |
| **Day 4** | `src/safety/` + `src/evaluation/` | حواجز الأمان، كشف الهلوسة، وقياس Precision@K والوفاء النصي. |
| **Day 5** | كافة الوحدات + `notebooks/06_end_to_end_demo_day5.ipynb` | العرض النهائي التفاعلي أمام لجنة التحكيم. |
