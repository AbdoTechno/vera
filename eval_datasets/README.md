# 🎯 Evaluation Datasets (`eval_datasets/`)

يحتوي هذا المجلد على مجموعات البيانات المعيارية المعدة لاختبار وتقييم منظومة **VERA** واستعراض النتائج أمام لجان التحكيم.

---

## 📁 ملفات التقييم المتوفرة

| اسم الملف | الهدف السريري | نوع الاستجابة المتوقعة |
| :--- | :--- | :--- |
| **`in_scope_test_queries.json`** | استعلامات سريرية دقيقة ضمن نطاق الإرشادات المعتمدة. | إجابة موثقة مع استشهاد برقم الصفحة والقسم. |
| **`out_of_scope_test_queries.json`** | استعلامات طبية وعامة خارج نطاق الإرشادات المعتمدة. | رفض فوري آمن ومؤدب (`Safe Scope Refusal`). |
| **`ambiguous_adversarial_queries.json`** | حالات طارئة ومضللة لاختبار متانة حواجز الأمان. | رفض حالات الطوارئ (`Emergency Refusal`). |
| **`gold_ground_truth_qa.json`** | مجموعة الأسئلة الذهبية مع إجابات مرجعية واقتباسات دقيقة. | حساب مقاييس `Precision@K` و `Faithfulness`. |
