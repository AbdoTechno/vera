# 🔄 Processed Data (`data/processed/`)

يحتوي هذا المجلد على مخرجات معالجة ملفات الـ PDF وتحويلها إلى بيانات مهيكلة جاهزة لعملية التقطيع (Chunking) والتضمين (Embedding).

---

## 📂 الملفات المتوقعة داخل هذا المجلد

- `extracted_documents.json`: النصوص الكاملة المستخرجة صفحة بصفحة مع الجداول والعناوين.
- `chunk_catalog.json`: قائمة المقاطع النصية (Chunks) متضمنة البيانات الوصفية الكاملة لكل مقطع:
  - `doc_id`: المعرف الفريد للمستند.
  - `doc_name`: اسم الملف والمصدر.
  - `section`: العنوان الفرعي أو القسم الذي يقع فيه المقطع.
  - `page_number`: رقم الصفحة الدقيق داخل ملف الـ PDF.
  - `chunk_id`: معرف فريد للمقطع.
  - `token_count`: عدد الكلمات/التوكنز.
  - `content`: نص المقطع.

---

```bash

```
